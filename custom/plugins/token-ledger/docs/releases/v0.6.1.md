# TokenLedger v0.6.1

Released 2026-09-29. Distribution release: TokenLedger is now on npm as [`paseo-token-ledger`](https://www.npmjs.com/package/paseo-token-ledger) and listed on [paseo.cafe](https://paseo.cafe/plugins/token-ledger). Plugin behavior is unchanged from v0.6.0.

## Compatibility and install

Requires Paseo **0.9.1–0.9.x** on both the daemon and the app. Use `v0.5.1` with Paseo 0.8.

```bash
paseo plugin install npm:paseo-token-ledger
```

Or from GitHub:

```bash
paseo plugin add stv1024/token-ledger --ref v0.6.1
```

Existing GitHub installations keep working and can keep updating from Git. To switch to npm, run `paseo plugin remove token-ledger` and then the npm install; the ledger in `~/.paseo/plugins/token-ledger/` is kept.

## Changes

- npm package with plugin sources only (no tests), plus description, license, repository, and keywords metadata.
- README screenshots moved to `images/`; new Install and Limitations sections.
